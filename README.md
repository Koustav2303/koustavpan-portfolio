🚀 CORE SUB-SYSTEMS
🧠 HexaBot v3.0 (Autonomous Client-Side Entity)
A fully draggable, integrated AI terminal that processes natural language queries regarding my professional background, strictly within the browser's memory.

Heuristic Scoring Engine: Tokenizes user input, scores the array against a categorized knowledge base, and gracefully handles typos.

Physics-Bound UI: Leverages framer-motion drag controls, allowing users to physically reposition the terminal across the DOM viewport.

📊 2.5D Holographic Data Matrix (GitHub Pipeline)
A cyberpunk-themed, multi-layered visualizer for real-time GitHub contribution data.

True Parallax Rendering: Uses exact mouse coordinates mapped to useSpring hooks to calculate the physical tilt (rotateX, rotateY) of a glassmorphism chassis.

Opposing Grid Physics: The background grid coordinates move inversely to the mouse vector, tricking the human brain into perceiving deep 3D physical space without the massive GPU overhead of WebGL.

🗃️ 3D Project Matrix & Verification
Coverflow Engine: Projects are displayed using a high-performance Swiper.js 3D coverflow carousel with custom glassmorphism depth masking.

Embedded Documentation: Features a secure, unclickable embedded PDF viewer displaying official self-declaration documents directly within the DOM.

📡 Advanced Communications Relay (Contact UI)
Holographic Radar: Utilizes a custom inverted SVG world map with a pulsing 12.97° N, 77.59° E (Bengaluru) geospatial beacon.

Direct Form Injection: The contact form bypasses traditional SMTP servers, seamlessly formatting user input and injecting it directly into a secure WhatsApp API intent for instant communication.

⚡ PERFORMANCE OPTIMIZATION
This system is engineered for maximum frame rates.

GPU Acceleration: Heavy animations, blurs, and sweeping gradients are forced onto the GPU using transform-gpu and will-change.

Mobile-First Rendering: Computationally expensive CSS properties are dynamically stripped from mobile viewports to guarantee smooth scrolling on lower-end devices.

⚙️ DEPLOYMENT PROTOCOL
To instantiate this environment locally, execute the following boot sequence:

Bash
# 1. Clone the repository into local memory
git clone [https://github.com/Koustav2303/koustavpan-portfolio.git](https://github.com/Koustav2303/koustavpan-portfolio.git)

# 2. Access the root directory
cd koustavpan-portfolio

# 3. Install required node dependencies
npm install

# 4. Ignite the Vite development server
npm run dev
📡 Server Uplink (GitHub Pages)
This repository is pre-configured with the gh-pages deployment package. To push local changes to the live domain:

Bash
git add .
git commit -m "System update"
git push origin main
npm run deploy
